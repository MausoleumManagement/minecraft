## Observable

To use Observable, we need operator permissions

```
k -n minecraft exec -it deploy/minecraft -- rcon-cli op 5500PowerLiches
```


We then have to set a keybind to access the client side GUI for it.

Options > Controls > Keybinds > click little "category thingy" > search for observable > set button for observable gui


Opening the gui, we can add a tps performance overlay and also pull a funny report. That gets sent to some website and we get a URL back.
